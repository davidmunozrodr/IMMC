# IMMC
IMMC: Internal model modular controller.
Created by David Munoz and Giacomo Severini.
The IMMC is a neural controller to replicate a variety of motor task including 1) Standing, 2) Forward walking (seven different speeds), 3) Backward walking, 4) Stand-To-Walk, Walk-To-Stand, Stand-To-Backward-Walk, and Backward-Walk-To-Stand.

In the repositories you can find all the files needed to run the model on MATLAB. You just need to open sim_IMMC, run the script, and select the motor task.

The model is sensitive to the MATLAB version and the setting of your system, so it is possible the gains in this file cannot display the expected motions.
